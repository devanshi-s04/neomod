\textit{Notes.}
F$_1 = 2\,P\,R\,(P+R)^{-1}$ where $P=$ purity $=1-$contamination and

Completeness = fraction of true NEOs selected;
contamination = fraction of selected candidates that are non-NEOs.
All passes used the same Sorcha hybrid S3M+MPCORB simulation
